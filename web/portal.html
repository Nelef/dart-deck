    별이 AI

    디스코드 서버 관리 봇입니다. 관리자가 말로 시키면 AI 컨시어지가 실행 계획을 짜고 봇이 레벨 보상 · 역할 · 자동 관리 같은 설정을 바꿉니다. 위험한 작업은 한 번 더 확인받습니다.

    byori.uk 열기 ↗
    1. 말로 부탁
      "레벨링 켜고 쿨다운 30초로 해 줘"
    2. 실행 계획
      LLM 이 AI 액션 38종 안에서 고르고 값을 채움 — 명령 목록은 봇이 켜질 때마다 자동으로 맞춤
    3. 위험도 확인
      safe 는 바로 · caution 은 한 번 확인 · danger 는 대상을 밝혀 확인
    4. LangGraph 로 차례로 실행
      여러 설정을 한 번에 — 계획 · 실행 · 결과 정리
    5. 봇이 설정 변경
      LLM 이 멈추면 키워드로 대신 응답 · Gemini · Kimi · Claude 어댑터
    안전 예시강퇴 · 차단 같은 액션은 여러 설정을 한꺼번에 하는 자동 실행에서 빼고, 사람이 버튼으로 확인할 때만 실행합니다.

    청약 레이더

    서울 · 경기 청약 공고를 여러 게시판과 공공 API에서 모아 새 공고와 접수 일정을 알립니다. 요청하면 AI가 공고문을 읽어 필요한 현금과 납부 일정을 정리합니다. 데모는 개인 메모와 조건을 뺀 사본 데이터로 열려 있습니다(수집, 알림, AI 분석은 꺼 둠).
