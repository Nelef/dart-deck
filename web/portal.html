발표 자료 AI

DART Deck

발표 자료를 열어 두고 오른쪽 AI 창에 고칠 점을 말하면, 에이전트가 고친 뒤 화면을 찍어 스스로 확인합니다. 반영은 사람이 [적용]을 눌러야 됩니다.

  • Claude Code 에이전트 — 원본이 아닌 사본을 고치고 캡처로 검증
  • 한 페이지는 바로, 여러 페이지는 계획을 먼저 보여 주고 진행
  • 공시(DART 사업보고서) 근거 검색 · 자료 생성 준비 중
데모: 예시 발표 자료가 AI 창이 열린 채로 뜹니다. 자유롭게 말해서 고쳐 보세요 — 방문할 때마다 원래 자료로 다시 시작합니다.

법령 RAG

법숲

중고거래 · 환불 · 사기 · 개인정보 · 금융 거래처럼 일상에서 부딪히는 법적 질문에, 법령 조문을 근거로 답합니다. 근거가 없으면 답하지 않습니다.

  • 생활 · 금융 법령 15개 · 2,437개 조문, BM25 + bge-m3 하이브리드 검색
  • 근거가 부족할 때만 다시 찾는 LangGraph 에이전트 · MCP 서버
  • 평가(질문 126개 중 시험 31문항): 정답 조문 hit@5 0.90 · 답변 정확성 30/31 · 범위 밖 질문 10/10 거절
데모: 예시 질문은 미리 만든 답변을 보여 주고, 직접 한 질문은 시간당 횟수 안에서 실시간으로 답합니다.
